Settings

Configure the catalog integrations.

TMDB credentials are required for movie, TV and anime catalog information. Create a developer account and obtain an API Read Access Token from TMDB. This standalone app stores the token in this browser and sends it directly to api.themoviedb.org. A production deployment should keep API credentials on a server instead of exposing them in client-side code.

TMDB provides metadata and availability information, not video streams. Atlas does not proxy, scrape or embed unauthorized streams. Where provider availability is listed, use the official TMDB availability page to continue.
