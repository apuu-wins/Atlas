Atlas’s Favorites, Queue, Recently played, and playlists are stored locally in this browser. They are not your YouTube Music account library. In-app catalog search uses Google’s official YouTube Data API v3 and your own API key; the key is stored only in this browser and sent to Google with search requests, and is not included in Atlas exports. A browser-only key is visible to this browser and should be restricted to YouTube Data API v3 and your hosted site’s referrer. When opened directly as a local file, referrer restrictions may not work as expected. Without a key, Atlas opens YouTube search externally. Playback uses YouTube’s official embedded player with its video, controls, and branding; audio-only/background playback and ad removal are not provided. Atlas does not access your personal YouTube Music account library.

Appearance

Browsing

Proxy integrations are unavailable in this build. No proxy server is connected or configured.

Session restore reopens Atlas sections and saved destinations; it does not restore a website's private session, form state, cookies, or embedded page state.

Search

Shortcuts: !g Google · !ddg DuckDuckGo · !p Perplexity · !brave Brave Search · !bing Bing. Suggestions are off; Atlas does not send typed text to a suggestion service. Search providers receive your query when you submit it.

General

Advanced

Proxy engines (Scramjet, Ultraviolet, and Rammerhead) are not configured or available in this file. This build does not provide a proxy endpoint, service worker, transport, or server integration. I have not added third-party proxy endpoints.

A local HTML file cannot register a service worker. Static hosting provides an HTTPS origin, but a proxy still needs its own compatible hosted server and runtime files. A normal cross-origin iframe cannot expose another site's live URL, title, or favicon to Atlas.

Atlas stores preferences, bookmarks, search history, and Atlas-initiated visit history in this browser's local storage. Search and destination sites receive requests only when you submit/open them. Existing LuminSDK and YouTube embed features still contact their respective external services.

Keyboard shortcuts: Alt+Shift+N opens a new Atlas tab; Alt+Shift+S opens Settings; Alt+Shift+H returns to Home. Browser-reserved shortcuts are left alone.
